# Accepted Sim2Science paper

[`paper.pdf`](paper.pdf) is the final camera-ready version of **When the Simulator Is Wrong, Do Better Derivatives Improve Decisions?**, accepted at the Sim2Science workshop at NeurIPS 2026.

The main text ends on page 5. Acknowledgments begin on page 6, followed by references, the completed NeurIPS checklist and appendices.

To rebuild the paper, keep these files together:

- `main.tex`
- `checklist_s2s_CR.tex`
- `neurips_2026.sty`

Upload this folder to Overleaf, or run `tectonic main.tex` with Tectonic installed. No external figures or bibliography files are required. The official style file is unmodified. Source-only drafting comments have been removed; the manuscript content matches the checked PDF.
